# MarketPlace — plantilla base de marketplaces

> Estado: planificación arquitectónica. No hay aplicación implementada todavía.

MarketPlace es un **repositorio base reutilizable** para crear múltiples marketplaces web **independientes**, inicialmente orientados a Bolivia. No es, por defecto, una plataforma multi-tenant.
