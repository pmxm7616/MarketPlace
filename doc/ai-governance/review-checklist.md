# Checklist de revisión

- [ ] Alcance coincide con la tarea y criterios REQ.
- [ ] Contratos, módulos, nombres y tipos respetados.
- [ ] Validación y autorización comprobadas en servidor.
- [ ] No hay secretos ni datos sensibles en código o logs.
- [ ] Caché, migraciones y concurrencia revisadas cuando aplica.
- [ ] Pruebas positivas, negativas y de regresión ejecutadas.
- [ ] No se debilitaron pruebas para pasar controles.
- [ ] Resultados y comandos documentados sin inventar PASS.
- [ ] Documentos y decisiones actualizados.
- [ ] Riesgos y rollback identificados.
- [ ] Revisión humana en cambios de alto riesgo.

Marcar no aplicable con justificación. Este checklist no sustituye CI.
