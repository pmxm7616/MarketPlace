## Idioma
- Código, identificadores, nombres de archivos y mensajes de log: **inglés**.
- Documentación de arquitectura, decisiones y tareas: **español**.
- Textos visibles al usuario: español como idioma inicial; preparar internacionalización sin inventar traducciones.
- Términos de dominio técnicos y nombres de bibliotecas permanecen en inglés cuando resulte más claro.

## Calidad mínima
TypeScript estricto; formato uniforme; evitar complejidad accidental; interfaces públicas estables; comentarios para explicar el porqué y no repetir el qué; pruebas enfocadas en comportamiento.
